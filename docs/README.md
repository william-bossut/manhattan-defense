# Manhattan Defense — Docs Index

"The Ascent": an endless, Asteroids-style arcade game where you climb from
street level to orbit above a red-lit, pixel-art Manhattan. No levels — the
world gets harder and the background changes the longer you survive.

- [`concept.md`](concept.md) — the game idea and core loop
- [`style-guide.md`](style-guide.md) — palette, fonts, effects (from Open Island / OpenBand)
- [`research.md`](research.md) — engine choice, templates, free assets, licenses
- [`decisions.md`](decisions.md) — decision log (what we chose and why)
- [`roadmap.md`](roadmap.md) — MVP scope and later ideas
- [`devlog.md`](devlog.md) — dated work-session notes
